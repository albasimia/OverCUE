# Devices UI Swift 6 actor isolation build fix

- Change ID: `20260902T001500-1c0f6a`
- 日時: 2026-09-02 00:15 +0900

## 発端

`aec716a`をmacOSローカルで`swift build`したところ、今回追加したDevices / Preset管理コードにSwift 6 actor isolationエラーが出た。

- `ACK05DeviceIdentifierMonitorError.errorDescription`から`@MainActor`の`L10n.text`を非isolated同期contextで呼んでいた。
- `PresetGroupStoreError.errorDescription`でも同じ問題があった。
- `@MainActor DeviceManagementModel`のnonisolated `deinit`から、non-Sendableな`ACK05DeviceIdentifierMonitor?`へアクセスしていた。

## 修正

- 既存`ACK05InputMonitorError`と同じパターンで、両LocalizedErrorを`@preconcurrency LocalizedError`とし、`errorDescription`を`@MainActor`へ隔離した。
- `ACK05DeviceIdentifierMonitor`はIOHID callbackをMain RunLoopへscheduleし、UI側もMainActorからのみ操作する設計であるため、deinit境界で保持できるよう`@unchecked Sendable`を明示した。

## 検証状態

GitHub connector経由の修正のため、このcommitではローカルbuildを実行できない。macOS側で`swift build`を再実行し、次に出るcompiler errorがあれば継続して閉じる。
