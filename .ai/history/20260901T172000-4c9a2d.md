# Generic HID追加レビュー3件を修正

- Change ID: `20260901T172000-4c9a2d`
- 作成日時: 2026-09-01 17:20:00 +0900

## 目的

commit `bef4c46 feat: add non-UI multi-device HID foundation`の追加レビューで見つかった、Action sourceのACK05依存、relative方向のmapping消失、stale Identify descriptor Rebindの3件を、実機データやUI仕様を仮定せずCore境界で閉じる。

## 修正

1. `ActionEvent`へgenericな`ActionSourceID`と`activationCount`を追加した。ACK05の`sourceKey`は既存Bridge / checks互換のdeprecated accessorとして残し、新しいadapterは`sourceID`を使える。
2. Generic HIDへ`GenericHIDActivation`と`GenericHIDInputBindingKey`を追加し、press / relative positive / relative negativeを別mappingとして扱う。Learnもrelative符号を保持する。
3. Generic HID Action resolverはhold / repeat状態を`ActionSourceID`で管理し、別physical sessionを混同しない。relative deltaの絶対値は`activationCount`へ保持する。
4. descriptor-only Generic HID mapping APIは既存374 checksをコンパイル互換に保つためdeprecated overloadとして残した。新規実装では使用しない。
5. Rebindは対象sessionがconnected setに存在し、descriptorが一致することを必須化した。Identify後に切断されたdescriptorを同一Serialの別sessionへすり替えない。
6. `OverCUECoreTests`を追加し、relative方向/量、Generic hold source、stale Rebind拒否の回帰を固定した。
7. config schema、Devices UI、Generic HID runtime mapping、Koolertron固有処理は変更していない。
