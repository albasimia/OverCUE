# Remove obsolete HID Learn monitor and reduce runtime hot-path work

- Change ID: `20260904T084205-a76908`
- 作成日時: 2026-09-04 08:42:05 +0900

## 目的

試行錯誤後に残った不要コードを削除し、現行操作を維持したままSIDE経路の重複処理を削減する。実機操作ができないため、体感遅延とDeck3 Learn不具合を修正済みとはしない。

## 実施内容

参照のない旧exclusive GenericHIDLearnMonitorを194行削除。Learn保存後の診断件数取得専用sidecar再読込と古いBroker説明を除去した。

Group Preset status読込はrevision比較で未変更configの再decodeを避ける。通知、atomic replace、symlink先変更、不正/欠損ファイルを考慮。編集baseline・書込lockには使用しない。

Generic HID immutable element metadataをlive interface/cookie単位にcacheし、remove/stop/startで破棄。shortcut解析をraw文字列単位でcacheする。HID callbackの元timestampを任意診断へ追加した。

棚卸しの削除/保持理由と次回測定手順をdocsへ記録。使用中のcaptureフラグ・HID open retry・native suppressionは残す。
