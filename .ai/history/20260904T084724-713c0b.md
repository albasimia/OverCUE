# Ignore Windows build outputs and generated site

- Change ID: `20260904T084724-713c0b`
- 作成日時: 2026-09-04 08:47:24 +0900

## 目的

Windowsとサイトの生成物を未追跡一覧から除外し、誤commitを防ぐ。

## 実施内容

Windows配下のbin/、obj/、artifacts/とルート_site/を.gitignoreへ追加。ソースやユーザーバックアップを広く除外せず、実ファイルは削除しない。

### 対象ファイル

```text
M	.gitignore
```

## 検証

git check-ignoreでDLL、obj、生成HTMLが除外され、Windowsソースパスは除外されないことを確認。git statusのWindows/・_site/表示が消え、git diff --check成功。コード変更なしのためbuildは再実行していない。

## 残課題

なし。
