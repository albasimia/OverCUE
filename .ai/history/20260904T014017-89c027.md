# Separate editor Preset ownership and unify Learn sessions

- Change ID: `20260904T014017-89c027`
- 作成日時: 2026-09-04 01:40:17 +0900

## 目的

監査で確認したPreset feedback loopとUnified Learnの不安定性を、通知抑止ではなくstate ownershipの分離で解消する。Shortcuts editor、Logical Device別runtime、Group Preset orchestration、Generic HID mapping persistenceの責務境界を固定する。

## 実施内容

- `ShortcutSettingsModel`のPreset / Mode操作をeditor-onlyにし、Runtime Status observerからeditor selection、Mode、mapping reloadへの書き戻しとruntime control送信を除去した。
- default Profileのruntime statusをphysical session別に保持するregistryを追加し、non-default isolationとdisconnect時のtarget解放を固定した。
- Group Preset assignmentをACK05 / Generic HIDのruntime開始Presetへ適用しつつ、通常statusでCycle Presetを巻き戻さない境界を維持した。
- Generic HID mappingの表示・削除をeditor Preset scopeへ変更し、Learn保存先を入力元Logical Device + Learn開始時editor Presetへ固定した。
- Unified Learnの純粋state machineを追加し、ACK05 / Generic HID backendの開始失敗を独立化、first-winner claim、単一terminal cleanup、進行中sessionの置換拒否を実装した。
- status suppression gateと`GenericHIDShortcutCaptureBroker`を撤去した。
- runtime ownership、mapping scope、backend独立性、Preset pinning、session置換拒否のunit / Core checksを追加した。
