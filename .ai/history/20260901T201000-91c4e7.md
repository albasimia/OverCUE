## 発端

現行Shortcut GUIを実画面で確認したところ、rekordboxショートカット一覧がすでにBrowse / Deck 1 / Deck 2 / Deck 3 / All Decks / Sampler / Recordings / General / View等へ分類されていた。一方で画面上部にはGroup-level「対象Deck」があり、対象scopeを二重指定していた。

また複数デバイス運用を考えると、1台のACK05を特定Deck専用にせず、Loop等の機能をDeck 1 / 2 / 3横断でまとめるユースケースが成立する。現行のGroup-global targetDeckではこれを標準Actionとして表現できない。

同時に、Preset切替用途は4 Groupでは不足し得るため、24程度まで扱えるnamed Preset GroupとドロップダウンUIが適切という合意になった。

## 合議結果

- targetDeck / `rekordboxDeck`はUI・config・runtimeのGroup-global stateとして不要。
- Deck targeting自体を別設定として残すのではなく、rekordbox一覧から選択されたshortcut/action自身のscopeとして保持する。
- 各Shortcut編集に別Deck dropdownを追加する案も二重管理なので不採用。
- Preset Groupはstable ID + name + orderを持つ可変構造、当面上限24。
- UIはGroup番号ボタンからname付きdropdownへ変更する。
- Cycleは存在するPresetだけをorder順に巡回する。
- Shortcut画面は現在のデバイスマップ幅を維持し、Device操作の第3カラムを追加しない。
- Device管理はDevicesタブへ分離し、主要タブはShortcut / Devices / Settings。LearnはDevices内操作とする。
- 旧Decision `20260830T200000-28631d`は置換済みとする。
- 実装時はv9→v10 migrationで既存Groupの意味を保持し、旧`rekordboxDeck`をscope付きshortcut referenceへ変換した後に削除する。
