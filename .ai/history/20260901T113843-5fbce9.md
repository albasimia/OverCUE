# 複数ACK05の入力状態とLogical Device bindingを分離

- Change ID: `20260901T113843-5fbce9`
- 作成日時: 2026-09-01 11:38:43 +0900

## 目的

複数ACK05の入力が単一のAction resolver、長押し、リピート、ダイヤル、波形状態を共有していた構造を解消する。同時にPhysical DeviceとLogical Deviceを分離する永続モデルを導入し、Generic HIDへ拡張する前提を作る。

## 実施内容

- CLI bridgeを物理IOHID deviceごとのcontroller factory / router構造へ変更し、接続・入力・切断をdevice source付きで処理するようにした。
- ACK05ごとにInputActionResolver、Cue hold、Jump repeat、ダイヤル加速、波形ドラッグ、Group / Deck / Profile状態とkeyboard outputを分離した。
- config version 9へ更新し、Logical Device、Physical Device Binding、VID / PID / Serial優先のidentity、LocationIDによる非永続Rebind hintを追加した。
- version 8以前の`deviceProfiles`をLogical Device + legacy Physical Bindingへ移行し、重複する旧mapはmigration後に除去した。
- 未登録deviceのdefault Profile fallbackは維持しつつ、初回入力時の自動登録・自動保存を廃止した。
- GUIのACK05 capture monitorも直前キー状態を物理deviceごとに分離した。
- Core checks、現行仕様、README、AAL project / nextを新しい現在地へ更新した。
