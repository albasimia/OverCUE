# Preset Group / Shortcut Scope version 10を実装

- Change ID: `20260901T225039-d63cd6`
- 作成日時: 2026-09-01 22:50:39 +0900

## 目的

Group単位の対象Deckという二重管理を廃止し、選択したrekordbox shortcut自身がscopeを持つ構造へ移行する。既存4 Groupをstable ID・name・orderを持つ可変Preset Groupへ変換し、既存設定とsemantic Action behaviorを維持する。

## 実施内容

- `ActionTarget.rekordboxAction(ActionID, commandID:)`と永続表現`rekordbox-action:<action-id>:<commandId>`を追加した。Cue hold / Jump repeat等はsemantic Actionから解決し、Generic `rekordbox:<id>`とInternal Actionは従来値を維持する。
- config version 10と`OverCUEPresetGroup`を導入した。Presetはopaque stable ID、必須name、order、Mode、waveformPosition、key/chord/dial mappingを持ち、1〜24個の可変構造とした。
- v9→v10 migrationで旧Group番号を決定的stable IDと`Group N`名へ変換し、旧`rekordboxDeck`を標準Actionのscope変換だけに使用した。v10 encodeには`groupMappings`と`rekordboxDeck`を出力しない。
- DefaultKeyMappingをv10へ更新し、旧Group 2 Deck 2とGroup 3 EXPORTを含む既存の意味を維持した。
- BridgeからGroup-global Deck stateを削除し、実在Presetをorder順にcycleするよう変更した。Runtime Status / Controlにはstable Preset IDを追加し、削除済みIDへのcontrolを拒否する。
- GUIからDeck selectorと固定4 segmentを削除し、Preset名menuへ変更した。disk reconcile後もstable IDで同じPresetを選択し続ける。
- 3-way mergeをPreset stable ID単位へ変更し、name/order/mapping fieldと辞書entryのlocal/remote変更を保持する。
- README、利用者向けdocs、現行仕様、AAL project/next/Decisionをversion 10実装へ同期した。Decision supersede metadataもAAL形式へ修正した。
