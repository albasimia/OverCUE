# Validate SIDE official lighting mode fields

- Change ID: `20260905T195233-be959a`
- 作成日時: 2026-09-05 19:52:33 +0900

## 目的

SDTech Option 1.0.3の公式mode番号と照明config fieldを静的・実機の両面で確認し、
押下modeと呼吸modeがper-key RGB、global palette、単色HSVのどれを使うか特定する。

## 実施内容

- 対象layoutのmode 0〜5と、公式UIが各modeで公開するbrightness/speed/direction/
  color/paletteの対応を再解析した。
- offset 11がpaletteと単色HSVを切り替え、offset 13〜15がHSVであることを実機確認した。
- Serial `592B14678182`だけへ正規mode sequenceを有限回送信し、既存evidenceと合わせて
  mode 0〜5の`06 16` response configを比較した。
- mode 3は押下キー単位で発光するがper-key RGBを使わず、paletteまたはglobal HSVを使うと確認した。
- mode 2へ単色赤を設定すると、全キーが色を変えず赤のまま消灯まで呼吸すると確認した。
- effect対象key/mask fieldは公式layout/UI/call siteに見つからず、offset 12も直接maskではない。
- probeへ正規mode限定commandと、mode 2/3の公式単色赤commandを追加した。
- deviceはRGBを書き換えずmode 5へ戻し、最終readbackに成功した。
