# 複数ACK05基盤のレビューゲートを解消

- Change ID: `20260901T120837-f34729`
- 作成日時: 2026-09-01 12:08:37 +0900

## 目的

commit `3a81b4e`のレビューで指摘された4ゲートを解消し、複数ACK05基盤が同一Serial、runtime通知、旧LocationID、GUI captureで物理device間の状態を再混在させない前提を確定する。

## 実施内容

- live session IDをIOHID接続インスタンス由来transport identifierへ固定し、Serial由来persistent identityと分離した。
- 同時接続中の同一VID / PID / Serialをambiguous bindingとしてdefault Profileへ戻すresolutionを追加した。接続トポロジ変更を全controllerへ即時通知し、既存holdを含むstateを再評価する。
- Runtime Statusへsession device ID、Logical Device ID、Profile名、device scopeを追加し、Controlをdevice / global scopeで明示した。対象外controllerはdevice controlを無視する。
- GUIはruntime status受信時にconfigへ書き戻さず、source Profileがdefault Profileと一致する場合だけ表示を同期する。接続後のGUI controlは最後に操作したsession deviceへ送る。
- legacy `location:XXXXXXXX` migrationからpersistent matchを除き、`lastKnownLocationID` hintだけを残した。非location旧識別値の後方互換は維持した。
- ACK05 capture callbackへsource device IDを追加し、最初の入力deviceへlockした。他deviceのキー／ダイヤルは無視し、source切断時はcaptureをキャンセルする。
- 回帰checks、3言語の切断メッセージ、現行仕様、AAL project / nextを更新した。
