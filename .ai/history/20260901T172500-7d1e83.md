# Generic HID旧Core checksとの互換形を維持

- Change ID: `20260901T172500-7d1e83`
- 作成日時: 2026-09-01 17:25:00 +0900

## 背景

`20260901T172000-4c9a2d`で`ActionEvent`の正本sourceを`ActionSourceID`へ移した結果、新しいdirection-aware Generic HID APIは意図通りgeneric sourceを返す一方、親commitから残る374 Core checksはdeprecated descriptor-only APIのイベント形まで比較している。既存checkを直接編集せず、新旧APIの境界を明確にしてコンパイル／意味互換を保つ。

## 修正

- direction-aware `GenericHIDInputBindingKey` APIは引き続きsession-aware `sourceID`と`activationCount`を返す。
- deprecated descriptor-only APIだけは旧`ActionEvent`形へ投影し、`sourceID=nil`、旧descriptor labelを返す。
- resolver内部のhold / repeat状態は新しいgeneric `ActionSourceID`のまま保持するため、互換投影によって新設計の状態分離は失わない。
