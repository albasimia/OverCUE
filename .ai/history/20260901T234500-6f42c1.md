# ACK05複数台実機証拠を反映しDevices UI / Preset管理を実装

- Change ID: `20260901T234500-6f42c1`
- 日時: 2026-09-01 23:45 +0900

## 実機確認

ACK05 2台を同時接続して`overcue-probe`で確認した。

- 2台ともSerial Numberは取得不可。
- 2台は異なるIOHID sessionとして接続。
- REPORT / VALUEのsource sessionは2台で混線しない。
- 片方を電源OFF→ONするとsessionは変化するが、PhysicalDeviceUniqueID / locationID / DeviceAddressは維持。
- Mac再起動後も2台それぞれのPhysicalDeviceUniqueID / locationID / DeviceAddressは維持。
- Bluetooth再ペアリング後はPhysicalDeviceUniqueID / locationID / DeviceAddressがすべて変化。

したがってPhysicalDeviceUniqueIDをACK05のPairing Identityとして採用し、再ペアリング時はIdentify / Rebindを要求する。

## 実装

- ACK05だけ、Serialがない場合にPhysicalDeviceUniqueID UUIDをpersistent Pairing Identityとして解決するCore処理を追加。
- ACK05 Pairing Identity用のRebind managerとCore testを追加。
- top navigationをShortcuts / Devices / Settingsへ変更。
- Devices画面を追加。
  - Logical Device一覧
  - Add ACK05
  - Identify / Rebind
  - Forget Binding
  - rename
  - Profile assignment
  - Pairing ID / connection状態表示
- Identify専用ACK05 monitorを追加。通常runtimeをUI側で一時停止して排他HID競合を避ける。
- Preset GroupへAdd / Rename / Delete UIを追加。最大24個。
- 最初のPresetは現行global Cycle bindingのSSOTであるため削除不可。
- Settingsをtop-level画面として追加。
- 日本語 / 英語 / 簡体字中国語のUI文言を同期。
