# runtime同期P1を閉じて非UI HID基盤を追加

- Change ID: `20260901T165629-6da708`
- 作成日時: 2026-09-01 16:56:29 +0900

## 目的

CLIが保存したruntime ModeをGUIの古いsnapshotがGroup往復後に巻き戻すP1を閉じる。その後、SwiftUI Devices画面やKoolertron固有仮定を追加せず、複数Physical HID DeviceをLogical Device / Profile / Action Layerへ接続する非UI基盤を実機データ待ちの境界まで進める。

## 実施内容

- GUIへdisk stateと未保存local差分をreconcileするsnapshot synchronizerを追加し、runtime status、process間config変更通知、Group切替で最新baselineを取り込むようにした。runtime status受信だけでは保存しない。
- CLIへconfig revision監視を追加し、ACK05 report処理前とGUI control前にbinding、Profile、Group mapping、Mode、Deck、波形位置を最新configから再構築するようにした。
- config内容とfile revisionを同じ`config.json.lock`保持中に読むsnapshot APIを追加し、古い内容へ新しいrevisionを対応させて更新を見逃す競合窓を閉じた。
- Device Registry、Identify、Rebind、ForgetのCore/APIを追加した。Rebindは一意なSerial identityだけを受理し、Logical Device / Profileは維持する。LocationID、Serialなし、同一Serial複数台、他Logical Deviceへbinding済みのdeviceは自動確定しない。
- Generic HIDの入力descriptor、keyboard / consumer / button / relative / absolute正規化、source-lock Learn、既存ActionEventへの変換を追加した。IOHID cookieは診断専用とし、同一structural signatureが複数なら永続化不可とした。
- `overcue-probe --all`へdevice session別metadata、Usage / Report、press/release、relative delta、duplicate count、永続化可否の表示を追加した。既存ACK05既定filterと`--seize`は維持した。
- config schemaはversion 9を維持し、Devices UI、Learn UI、Generic HID mapping永続化、Koolertron固有処理、Parent Preset / Sceneは追加していない。
- stale runtime、registry、identify、rebind/forget、ambiguous rejection、Generic HID normalization/Learn/Action、locked snapshotをCore checksへ追加した。
